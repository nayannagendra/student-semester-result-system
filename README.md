# Student Semester Result System

## About
A responsive web application to manage student semester marks and results.

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Java and Spring Boot
- Database: MySQL
- Build Tool: Maven

## Features
- Store and retrieve student information
- Enter MSE and ESE marks for four subjects
- Calculate total marks and percentage
- Display overall result
- Validate student data
- Manage student records through REST APIs

## Database
Database name: student_result_db
Table name: students
SQL script: database/student_result_db.sql

## Run the Application
1. Start MySQL.
2. Configure database credentials in application.properties.
3. Open a terminal in the project folder.
4. Run: .\mvnw.cmd spring-boot:run
5. Open http://localhost:8080
